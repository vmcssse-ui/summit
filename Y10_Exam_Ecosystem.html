02

The revision loop

Every companion page runs the same six moves, in the same order — because each one is built on how memory actually works.

Listen first

Play the episode. Tick it off. Write the one thing you are taking from it. Active listening beats background noise.

Brain dump

Close everything. Write down every single thing you remember, then re-listen and add what you missed in a different colour. Free recall — the single strongest revision method there is.

Listen and answer

Five questions from the episodes. Answer them, then mark yourself from the answers at the back. The testing effect. Marking your own work is half the gain.

Cover and write

Nine key words. Cover the meanings, write them from memory, then check. Retrieval, not recognition. Recognising a word is not knowing it.

Link it up

Explain WHY one thing leads to another, and connect it to a topic from earlier in the year. Elaboration — this is what separates a grade 5 from a grade 8.

Come back

Re-do the quiz a week later, then a month later. Track your score. Spacing. Forgetting a little, then retrieving, is what makes it stick.
