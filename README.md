## How the resources work

The pages are the navigation layer. Every lesson deck, scheme of work,
booklet and podcast button opens **SharePoint** and will ask for a school
login — the materials themselves stay behind school access.

All Grade 9 Summit buttons point at one folder:

```
Year 11 / Philosophy / Edu Ai - GCSE /
  KS4 Edexcel RS - Full Scheme of Work 3 (1) / Summit - Grade 9 Strand
```

Rename or move that folder and every button on every unit page breaks
together. That is deliberate — one folder, one base URL, one thing to fix.

## Updating the site

1. Edit or replace the `.html` files in this repository (drag and drop works —
   **Add file → Upload files**).
2. Wait a minute or two for GitHub Pages to rebuild.
3. Reload the live site. If you still see the old version, hard-refresh.

`index.html` carries a `SHOW_YEAR11` switch near the bottom: set it to `true`
to reveal the Year 11 section once those pages are uploaded.
